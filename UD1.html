1. Lenguajes de Programación: El Panorama Real

Existe una enorme variedad de lenguajes de programación en el mundo tecnológico (como C++, Java, C#, PHP o Python). Sin embargo, entre los más populares e influyentes destacan dos grandes gigantes:

  • Python: Famoso por su simplicidad y muy utilizado en investigación de Inteligencia Artificial y Ciencia de Datos.
  • JavaScript (JS): El lenguaje nativo de la Web. Se ejecuta directamente en todos los navegadores del mundo (Chrome, Firefox, Edge) sin necesidad de instalar nada.

Programación Visual (Bloques)

Usada en Scratch. Se basa en encajar piezas visuales para evitar errores de escritura.

  • Intuitiva y rápida de entender.
  • Imposible cometer faltas de ortografía (sintaxis).
  • Limitada para proyectos complejos y aplicaciones web reales.

Programación Textual (JavaScript / Python)

Entre la gran variedad de lenguajes existentes, JavaScript nos permite crear la IA y la interfaz web del ajedrez en el navegador.

  • Funciona en cualquier ordenador del instituto.
  • Permite conectar gráficos con inteligencia artificial.
  • Requiere atención al escribir llaves {} y puntos y comas ;.

2. Fundamentos de JavaScript: Equivalencias con Scratch

Todo lo que hacíais en Scratch con bloques de colores tiene una equivalencia exacta en código real de JavaScript:

1. Estructuras Secuenciales (Instrucciones en orden)

Las ordenes se ejecutan una tras otra, de arriba a abajo.

🐱 En Scratch (Bloques Apilados): [al hacer clic en bandera verde]
[fijar puntos a (10)]
[decir "¡Partida Iniciada!"]
💻 En JavaScript (Código Real): let puntos = 10;
console.log("¡Partida Iniciada!");

2. Estructuras Condicionales (`if`, `else if`, `else`)

Permiten tomar decisiones. Equivale al bloque si <...> entonces / si no de Scratch.

🐱 En Scratch (Bloque de Control): [si <(puntosIA) > (puntosHumano)> entonces]
  [decir "Ventaja IA"]
[si no]
  [decir "Ventaja Alumno"]
💻 En JavaScript (Código Real): if (puntosIA > puntosHumano) {
    console.log("Ventaja IA");
} else {
    console.log("Ventaja Alumno");
}

3. Estructuras Iterativas o Bucles (`for`, `while`)

Repiten acciones. Equivale al bloque repetir (8) o por siempre en Scratch.

🐱 En Scratch (Bloque Repetir): [repetir (8)]
  [analizar fila del tablero]
💻 En JavaScript (Bucle `for`): for (let fila = 0; fila < 8; fila++) {
    analizarFila(fila);
}

3. Variables: Asignando Valor a las Piezas

Para que la IA sepa si va ganando o perdiendo, usa Variables declaradas con let o constantes fijas con const.

En Scratch (Bloques)
fijar [peon] a (10)
fijar [caballo] a (30)
fijar [dama] a (90)
En JavaScript (Código Real)
const valorPeon = 10;
const valorCaballo = 30;
const valorDama = 90;
Pieza Variable en Código Valor Numérico Razón Estratégica
♟️ Peón valorPeon 10 puntos Unidad básica del tablero.
♞ Caballo / ♝ Alfil valorPiezaMenor 30 puntos Piezas menores de ataque rápido.
♜ Torre valorTorre 50 puntos Pieza pesada de gran alcance.
♛ Dama valorDama 90 puntos La pieza más poderosa del juego.

Actividades de Evaluación & Proyecto UD1

Para asegurar una excelente calificación en esta primera unidad, realizaremos primero una actividad guiada sencilla de afianzamiento y, a continuación, el reto práctico en el prototipo de código.

Criterios de Evaluación Oficiales:

  • Criterio 1.3: Entender cómo funciona un programa informático, la manera de elaborarlo y sus principales componentes (variables, condicionales y bucles).
  • Criterio 2.1: Conocer y resolver problemas desarrollando un programa informático y generalizando las soluciones tanto de forma individual como en equipo.

Actividad 1 (Individual): Test de Conceptos y Cálculo de Ventaja

Responde en tu cuaderno o documento digital a las siguientes cuestiones sencillas:

  1. Explica con tus palabras la diferencia entre declarar una variable con let y evaluar una condición con if.
  2. Cálculo de puntuación del tablero: Si en una posición del tablero las Blancas conservan 2 Peones (10 pts c/u) y 1 Torre (50 pts), mientras que las Negras conservan 1 Dama (90 pts):
    💡 ¿Cómo resolverlo paso a paso?
    • Paso A: Suma las piezas de las Blancas: (10 + 10 + 50) = 70 puntos.
    • Paso B: Suma las piezas de las Negras: 90 puntos.
    • Paso C: Compara ambas cifras (70 vs 90) e indica qué bando va ganando y por cuántos puntos de ventaja.
  3. Escribe en tu cuaderno una línea de código en JavaScript que cree la variable valorAlfil con un valor de 30 puntos.

Reto Práctico UD1: Programando el Cerebro de la IA

Actividad práctica en el archivo ia.js

📤 ¿Qué debes subir para que la tarea sea evaluada?

Una vez realizadas y comprobadas tus modificaciones en el ordenador de clase, debes subir a la tarea de Google Classroom / Moodle únicamente tu archivo modificado: ia.js.

🎯 Tarea A: Personalizar la Puntuación de Piezas Líneas 14-22 de ia.js

  1. Abre el archivo ia.js en tu editor de código (VS Code o Thonny).
  2. Busca el bloque de código var VALORES_PIEZAS = { ... }; indicado con el banner amarillo ✏️ TAREA A.
  3. Modifica los números para cambiar cómo valora la IA cada pieza. Por ejemplo, cambia la Torre (r: 50) a 60 o los Peones (p: 10) a 15.
  4. Guarda el archivo, recarga index.html en tu navegador y juega una partida para comprobar cómo reacciona la máquina.

🎯 Tarea B: Crear una Regla Condicional con 'if' Líneas 55-65 de ia.js

  1. En el mismo archivo ia.js, desplázate hasta la función evaluarTablero(juego).
  2. Busca el comentario destacado ✏️ TAREA B (ALUMNADO).
  3. Añade tu propia estructura condicional if para darle una ventaja extra a la IA. Por ejemplo, escribe la siguiente línea para otorgarle +10 puntos extra a la Dama:
    if (pieza.type === 'q') { valor = valor + 10; }
  4. Guarda los cambios y verifica en la Consola (F12) o en la pantalla de juego cómo se aplica tu nueva regla.
