🛠️ Plantilla de Prueba: Mi Primer Código JavaScript

Esta es la página de prueba facilitada por el profesor para la Práctica Guiada de la UD1 en 3º de ESO.

📌 Pasos para probar tu script:
  1. Crea un archivo llamado mi_script.js en la misma carpeta que este archivo HTML.
  2. Escribe tu código JavaScript dentro de mi_script.js.
  3. Asegúrate de haber conectado este archivo vinculando <script src="mi_script.js"></script> justo al final del HTML.
  4. Abre la consola del navegador pulsando la tecla F12 (o Clic derecho → Inspeccionar → Consola).
