Anatomía de un Robot

1. Grados de Libertad (GDL / DoF)

Los GDL son el número de movimientos independientes que puede realizar un robot.

Analogía: Tu Brazo (7 GDL)
  • Hombro: 3 GDL.
  • Codo: 1 GDL (Flexión).
  • Muñeca: 3 GDL.

2. Articulaciones

  • Rotacional: Gira sobre un eje.
  • Prismática: Se desliza linealmente.

3. Morfologías

  • Cartesiano: Ejes X, Y, Z (Impresora 3D).
  • SCARA: Rápido en horizontal.
  • Antropomórfico: Brazo articulado.

AGV: Automated Guided Vehicles

Vehículos autónomos que transportan materiales sin conductor.

Sistemas de Guiado:

  • Filoguiados: Siguen un cable/línea en el suelo.
  • Láser / LiDAR: Mapean el entorno.
  • Visión Artificial: Leen códigos QR en el suelo.

Arduino C++

Estructura Básica

Todo programa tiene dos partes:

  • void setup() { ... }

    Configuración. Se ejecuta una vez al inicio.

  • void loop() { ... }

    Bucle. Se repite infinitamente.

IMPORTANTE: ¡No olvides el punto y coma ; al final de cada línea!
sketch_robot.ino
int ledPin = 13;

void setup() {
  pinMode(ledPin, OUTPUT);
}

void loop() {
  digitalWrite(ledPin, HIGH);
  delay(1000);
  digitalWrite(ledPin, LOW);
  delay(1000);
}

Code Gym (5 Retos)

Entrena tu ojo de ingeniero. Encuentra los errores antes de cargar el código al robot.

Reto 1: El Olvidadizo

pinMode(13, OUTPUT)
digitalWrite(13, HIGH);
Falta el punto y coma ; en la primera línea.

Reto 2: Lógica Inversa

Queremos parar si el sensor mide MENOS de 10cm.

if (distancia > 10) { parar(); }
Error lógico: El símbolo debe ser < (menor que), no >.

Reto 3: El Pin Fantasma

El LED no se enciende con fuerza, apenas brilla.

void setup() { // Vacío }
void loop() { digitalWrite(13, HIGH); }
Falta configurar el pin en el setup: pinMode(13, OUTPUT);

Reto 4: Pesadilla de Llaves

void loop() {
  if(boton == 1) {
    encender();
}
// Fin del código
Falta cerrar una llave }. Una cierra el IF, pero falta la que cierra el LOOP.

Reto 5: La Trampa del Delay

El robot choca porque no lee el sensor a tiempo.

void loop() {
  avanzar();
  delay(5000); // Esperar 5 seg
  leerSensor();
}
delay(5000) "congela" al cerebro 5 segundos. En ese tiempo está ciego. Usa temporizadores sin delay (millis).
