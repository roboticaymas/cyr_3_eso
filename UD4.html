1. Introducción al Ecosistema de Datos

El término Big Data no se refiere solo a tener "muchos datos". Se refiere a conjuntos de datos tan grandes y complejos que el software de procesamiento tradicional no puede gestionarlos. Para que lo consideremos Big Data, debe cumplir (principalmente) con las 5 V:

📦

Volumen

Cantidad masiva de datos (Terabytes, Petabytes).

⚡

Velocidad

Datos generados y procesados en tiempo real.

🎨

Variedad

Texto, vídeo, audio, logs, GPS...

✅

Veracidad

Fiabilidad y calidad del dato.

💎

Valor

La utilidad que se extrae de ellos.

2. Metadatos: El ADN de la Información

Definición Técnica

Los metadatos son "datos sobre los datos". Es información estructurada que describe, explica, localiza o facilita la recuperación, uso o gestión de un recurso de información. Sin ellos, un archivo digital sería una secuencia de bits sin sentido para el ordenador.

Clasificación NISO (Estándar)

Los metadatos se dividen en tres categorías fundamentales:

  • 1. Metadatos Descriptivos: Sirven para descubrir e identificar.
    Ej: Título, Autor, Resumen, Palabras clave (Tags).
  • 2. Metadatos Estructurales: Indican cómo se organizan las partes de un objeto compuesto.
    Ej: Orden de las páginas en un PDF, capítulos de un vídeo.
  • 3. Metadatos Administrativos: Ayudan a gestionar el recurso.
    • Técnicos: Formato (.jpg), tamaño, compresión.
    • Preservación: Checksum (integridad), copias de seguridad.
    • Derechos: Copyright, licencias de uso.

Ejemplo Práctico: Un Tweet (X)

Lo que tú ves es el texto. Lo que la máquina ve es esto:

{ "created_at": "Fri Nov 24 12:30:00 +0000 2025", "id": 146000000000000, "text": "¡Aprendiendo Big Data en clase! 🚀", "user": { "id": 892384, "name": "Estudiante_3ESO", "location": "Madrid, España", // METADATO DESCRIPTIVO "followers_count": 150 }, "geo": { "type": "Point", "coordinates": [40.4167, -3.7037] // METADATO ADMINISTRATIVO (Ubicación) }, "entities": { "hashtags": ["BigData", "Colegio"], "media": [ { "type": "photo", "size": "1024x768" } // METADATO TÉCNICO ] } }

Formato JSON (JavaScript Object Notation), el estándar actual.

3. Almacenamiento y Ciclo de Vida

El Ciclo de Vida de los Metadatos

Los metadatos no son estáticos, tienen un ciclo desde que nacen hasta que mueren:

1. Creación Manual (escribir un título) o Automática (la cámara guarda el GPS).
➜
2. Almacenamiento Se guardan incrustados en el archivo o en bases de datos externas.
➜
3. Manipulación Se editan, se leen por algoritmos o se enriquecen.
➜
4. Eliminación Se borran por privacidad o porque el archivo se destruye.

A. Almacenamiento Incrustado (Embedded)

Los metadatos viajan dentro del propio archivo.

  • EXIF: Estándar para fotografías (Cámara, flash, ISO, GPS).
  • ID3: Estándar para MP3 (Artista, Álbum, Carátula).
  • Ventaja: Si copias el archivo, te llevas los datos.
  • Riesgo: Fugas de privacidad involuntarias.

B. Almacenamiento Desacoplado (External)

Los metadatos están en una base de datos separada del archivo.

  • Ejemplo Spotify: La canción está en un servidor, pero tus listas de reproducción están en una base de datos SQL.
  • Ventaja: Búsquedas rapidísimas (Big Data) y seguridad.
  • Uso: Motores de búsqueda, bibliotecas digitales, sistemas en la nube.

4. Data Scraping: Arquitectura y Ética

¿Cómo funciona realmente?

El Scraping no es magia, es una simulación de un usuario humano a ultra-velocidad. El proceso técnico consta de 3 fases:

  1. Request (Petición): El bot envía una petición HTTP a la web (como si tu navegador escribiera la URL).
  2. Parsing (Análisis): El bot descarga el código HTML y busca patrones específicos (ej: todos los elementos `div` con clase `precio`).
  3. Extraction & Storage: Copia el texto encontrado y lo guarda en una hoja de cálculo (CSV) o base de datos.

⚠️ La Línea Ética y Legal

No todo el scraping es legal. Antes de "scrapear", un programador ético debe revisar el archivo robots.txt de la web (ej: google.com/robots.txt). Este archivo le dice a los bots dónde tienen prohibido entrar. Ignorarlo puede llevar a bloqueos de IP o problemas legales (DDOS, Copyright).

PYTHON SNIPPET
import requests
from bs4 import BeautifulSoup

# 1. Hacer la petición
url = "https://tienda-ejemplo.com"
respuesta = requests.get(url)

# 2. Convertir HTML a objeto analizable
soup = BeautifulSoup(respuesta.text, 'html.parser')

# 3. Extraer datos (Bucle)
for item in soup.find_all('div', class_='producto'):
    nombre = item.find('h2').text
    precio = item.find('span', class_='precio').text
    
    print(f"Producto: {nombre} | Valor: {precio}")

Librerías comunes: BeautifulSoup, Selenium, Scrapy.
