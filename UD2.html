1. El Lenguaje HTML: El Esqueleto Semántico

HTML (HyperText Markup Language) no es un lenguaje de programación, sino un lenguaje de marcado de etiquetas. Su función es estructurar el contenido de una página web indicándole al navegador qué elemento es un título, qué parte es un párrafo, un botón o una imagen.

Estructura Básica de un Documento HTML5

<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <title>Aula de Jaque - IES Cañada Rosal</title>
</head>
<body>
  <header>
    <h1>Ajedrez con Inteligencia Artificial</h1>
  </header>
  <main>
    <p>Juega contra la máquina durante los recreos.</p>
    <button>Nueva Partida</button>
  </main>
</body>
</html>

Etiquetas Semánticas Clave que Debes Conocer

<header> Cabecera de la página. Contiene el título del juego, el logo del centro o el menú de opciones.
<main> Contenido principal único de la página (en nuestro caso, donde se aloja el tablero de ajedrez).
<div> Contenedor genérico para agrupar elementos (por ejemplo, la caja del marcador de puntos o el panel lateral).
<button> Botón interactivo que el usuario puede pulsar (ej: "Reiniciar Partida", "Cambiar Bando").

2. CSS: Dando Estilo, Color y Diseño a la Web

Si HTML es el esqueleto de un edificio, CSS (Cascading Style Sheets) es la pintura, la iluminación y la decoración. Nos permite cambiar colores, tamaños de letra, añadir bordes suaves y colocar los elementos exactamente donde queramos.

¿Cómo se Escribe una Regla CSS?

Una regla de CSS consta de un selector (a qué elemento aplicamos el estilo) y un bloque de propiedades y valores:

/* Cambiar el aspecto de los botones */
.btn-juego {
  background-color: #0284c7;
  color: white;
  padding: 10px 20px;
  border-radius: 8px;
  font-weight: bold;
}

💡 Los 3 Selectores Más Usados:

  • 1. Selector de Etiqueta: Modifica todas las etiquetas de un tipo (ej: button { ... }).
  • 2. Selector de Clase (.nombre): Modifica elementos con la clase dada (ej: .btn-juego). ¡Se puede reutilizar en varios botones!
  • 3. Selector de ID (#nombre): Modifica un elemento único en toda la página (ej: #tablero-ajedrez).

Maquetación Moderna con Flexbox

Para alinear el tablero de ajedrez al lado del panel de marcadores o centrar los botones en pantalla, utilizamos Flexbox (display: flex):

.contenedor-juego {
  display: flex; /* Activa la maquetación flexible */
  justify-content: center; /* Centra los elementos horizontalmente */
  align-items: center; /* Centra los elementos verticalmente */
  gap: 20px; /* Separación entre el tablero y el panel */
}

  • • Bordes redondeados border-radius: 12px y sombras proyectadas box-shadow.
  • • Diseño adaptable (Responsive) para pantallas pequeñas o monitores de clase.
